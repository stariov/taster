Plug in your keyboard. Taster finds it automatically.

A macro types text or presses keys for you. Put a macro on a key in Keymap → Macros.

How to write a macro
Hellotypes “Hello”
{KC_ENT}taps one key (here Enter)
{KC_LCTL,KC_C}presses keys together (here Ctrl+C)
{500}waits 500 milliseconds
{+KC_LSFT} … {-KC_LSFT}holds a key down … releases it
\{types a literal {

Typed text uses the US layout and plain ASCII characters only. Key names: hover over any key in the Keymap tab.
